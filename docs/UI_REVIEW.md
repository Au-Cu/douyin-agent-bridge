# 控制台界面验收

本次改动在 `ui/console-layout-review` 分支开发，基于 `aac0b3b878f75c466c840b0454e4cf7856f32b4a`。新版布局已由用户验收，随后按要求保留旧版入口，并获准更新正式控制台。合并与本机更新不会自动创建版本标签或 GitHub Release。

## 新旧界面

- 页面右上角“界面版本”可选择新版或旧版，随时可以切回。
- 新版以工作台为首页，运行状态、当前需求和任务优先显示；资料与设置各有独立页面。
- 旧版保留原来的卡片顺序、双列资料与任务区，以及原有浅色样式。
- 两版共用一个前端控制器和同一组后端接口，任务、消息、模型、授权与资料没有复制或迁移。
- 选择保存在当前浏览器、当前控制台地址下；刷新和重新打开会记住。更换浏览器或端口时可以重新选择。
- 配置或输入草稿尚未保存时会提示先保存，避免切换页面丢失输入。
- `/?ui=modern` 和 `/classic.html?ui=classic` 可明确指定入口，也用于重置浏览器选择。

## 任务与进度

任务与回复提供常驻的「人工核实 / 查看明细」，覆盖全部当前账号可处理的待核实回执，包括不在当前任务筛选中的历史记录。每条展示上次只读核验的时间和失败原因，可明确确认已收到或放弃回执；不明表情不会补点。单任务的送达核实入口也始终保留。

执行结果不明的任务另有「核实执行结果」，确认后仅读取已提交的准确原回合：仍在运行或证据不足时保留现场；已完成且有可识别最终答复时，可保存并排队交付缺失的结果。已有发送现场保持不变，不重新执行任务。文字送达不等于执行完成，超时说明单独计作通知。


任务卡保留归档/恢复、中断、重试记录、目标聊天跳转与送达核验。执行状态、文字送达和三个表情回执分开展示；详细错误与长说明按需展开。

“核实送达”可按任务或需求列出不明文字和表情。每条可以只读核验原聊天，人工确认送达，或明确放弃此回执；二次确认取消时不修改记录。核实不触发重发或任务执行；表情不提供重试点击。归档删除遇到送达阻塞会打开同一核实窗口。

全局提示固定在视口顶部居中，与顶部留出间距，采用 6 秒后自动收起的轻提示；长文限制高度并在内部滚动。提示不把页面卷回顶部，也不抢走当前操作焦点；新旧布局、窄屏及对话框内均可见。

抖音登录成功及组件已就绪的简短说明使用同一轻提示，可提供前往添加会话的链接，6 秒后收起；需要用户选择的登录模式、绑定与确认步骤仍保留到用户操作。

## 弹层分类

按用户要完成的事情与操作后果选择容器，两种界面共用行为，保留各自的视觉风格：

| 场景 | 容器 | 交互规则 |
| --- | --- | --- |
| 保存成功、已开始处理等短反馈 | 顶部居中轻提示 | 不抢焦点，6 秒后收起；悬停或键盘聚焦时暂停计时 |
| 后台同步中断 | 页面内持续提示 | 同一问题只更新原提示，提供重试；恢复同步后收起，不重复弹窗 |
| 连接、模式选择与绑定说明 | 可关闭的步骤卡片 | 保留所需的页面操作入口，不以强制遮罩阻挡登录或会话核验 |
| 操作错误 | 顶部居中轻提示或原操作区域内的错误 | 浮动提示 6 秒后收起；原操作区域的错误和后台同步异常保留到解决 |
| 笔记、连续画面、群聊历史 | 侧边阅读面板 | 面板内部滚动；手机铺满可用视口；关闭后保留原页面位置 |
| 送达核实与逐条处理 | 独立工作对话框 | 完整展示记录与操作，确认送达、重发、放弃分别说明结果 |
| 停止剩余回复、恢复新消息回复等局部决策 | 就近确认浮层 | 靠近实际触发按钮，不压暗或锁住背景；窄屏改为底部确认面板；默认聚焦取消 |
| 切换账号使用模式、换主号、清空上下文、重发等高影响决策 | 居中确认框 | 展示具体对象、后果与动作按钮，默认聚焦取消；不使用浏览器通用确认框 |
| 永久删除、开启到期永久清理 | 危险操作确认框 | 展示范围与后果，额外勾选后才能确认；删除提交期间不能关闭 |

确认框支持取消、Escape 和点击遮罩返回。切换页面或关闭来源工作面板时取消尚未提交的确认；同时只接受一项决定，不积压之后突然出现的确认框。状态不明的回复仍需单独确认接收方未收到，第一次同意重新排队不等于同意重发不明分段。后端的提交、删除、发送与送达核验边界不变。

局部确认使用原生 Popover，背景仍可操作。点击外部、Escape 或把焦点移到其他控件会取消未提交的决定；点击其他输入框后焦点留在该输入框。嵌套在送达核实窗口内时，浮层属于原窗口，关闭原窗口也会取消确认。浏览器不支持 Popover 时使用居中确认框。

确认来源使用实际点击的按钮，兼容点击不自动聚焦按钮的浏览器。轮询移除或更换原按钮、禁用原操作、切换页面时，未提交的决定失效；确认前再次核对来源。取消返回来源时保留滚动位置，来源已消失或用户正在操作其他控件时不抢回焦点。

此分类及交互用当前源码与合成数据验收；视频是否完成学习须以对应的全时段视觉记录为准。浏览器模拟窄屏、减少动态效果和两种布局的检查不代表手机或 macOS 实机验收。

已归档任务与需求提供独立的“彻底删除”入口。确认框展示关联数量，必须勾选永久删除说明；可取消或按 Escape 返回。确认框不随轮询重建。活动执行、未核实结果和发送现场由后端再次校验并拒绝删除。此功能仅清理本机桥接记录及相应缓存，原生聊天、项目、共享学习资料与备份保留；不可用恢复显示撤销。

视觉段数和覆盖秒数取自运行记录及已保存的视觉报告。操作通过收到的视频消息关联资料，不能按标题或当前需求猜测归属。旧缓存与本轮段数不匹配时不会充当本轮覆盖记录。没有可信数据时显示等待记录，不生成猜测的百分比。

轮询使用稳定节点更新，未变化的卡片不会重建。详情展开、键盘焦点、输入与可滚动内容保留；快速切换筛选时丢弃过期响应。支持减少动态效果。新版的深浅外观选择也保存在当前浏览器。

## 本地预览

要求与主项目相同：Node.js 24.5 或更新、已安装依赖。

```sh
npm run preview:ui
```

默认地址为 `http://127.0.0.1:39362/`。可用 `UI_PREVIEW_PORT` 更改端口，预览拒绝占用正式控制台默认端口 39361。

此入口只加载合成资料，在内存中模拟筛选、归档恢复、配置和任务中断。不会加载真实账号或数据目录，不会连接助手、打开抖音、发送消息、派发任务或访问本机项目。退出预览后演示修改清空。真实使用仍由原来的项目启动入口提供。

## 检查

```sh
npm test
npm run test:ui
npm run test:portable
npm run release:check
```

`test:ui` 在随机本地端口新建演示环境，检查两种布局、模型草稿保护、自动刷新稳定性、快速筛选、归档恢复、删除确认、中断入口、窄屏与减少动态效果。需要本机 Edge，或设置 `BRIDGE_TEST_BROWSER=chrome` 使用 Chrome。截图与结果写入被忽略的 `data/ui-review/`。

`test:portable` 使用独立的临时数据与合成助手，检查打包来源的真实 HTTP 服务、静态文件和原有安全边界，并通过浏览器在真实 SQLite 上完成合成需求的归档、取消删除与确认删除。通过这些检查不代表完成实际抖音收发、Mac Safari 或手机真机验收。本次布局共用浏览器端代码，没有新增平台专属依赖。
