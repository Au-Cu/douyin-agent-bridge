派发到已有 Codex 聊天需要桌面共用服务。准备完成后，完全退出桌面 Codex，再通过项目的“启动共享 Codex”入口打开；无需重新登录，也不会删除聊天。普通聊天与视频分析仍使用隔离的连接。

个人 Agent设置模型、推理强度与上下文预算

Codex 为默认后端。切换个人 Agent 后端后重启生效；旧需求和目标聊天保持各自后端。

个人 Agent 的回复、视频理解和派发任务使用这组配置；普通聊天独立设置。需求判断使用独立的轻量临时会话。快速模式会按 Codex 规则增加用量。

视频读取默认值

模型名单来自所选后端的本机登录，登录后可刷新。

普通聊天 AI个人 Agent 与普通聊天分别配置

个人 Agent 就是现有的用户单聊模式。普通聊天使用独立上下文，可查公开资料、计算和查询时间；启用容器后还可在隔离环境验证 Python 代码。本机项目、个人文件、账户、终端、浏览器操作和电脑控制保持关闭。群聊可选仅被原生 @ 时回复或回复所有新消息，每段回复原生引用触发消息。

普通聊天独立选模型；留空跟随所选后端默认，不跟随个人 Agent 的设置。保存后从下一轮起生效。

代码沙箱需先安装并启动 Docker Linux 容器引擎，再准备固定 Python 镜像。无宿主目录挂载、无网络，限 256MB / 30秒。环境不通过核验时不执行代码。
